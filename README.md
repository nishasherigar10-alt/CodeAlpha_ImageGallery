# CodeAlpha Image Gallery

## 📸 Project Description

This project is an interactive and responsive Image Gallery developed as part of the CodeAlpha Frontend Development Internship.

The gallery allows users to view images, open them in a larger lightbox view, and navigate between images using previous and next buttons.

## ✨ Features

- Responsive image gallery
- Previous and next image navigation
- Lightbox image view
- Hover effects
- Smooth transitions
- Keyboard navigation
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Open the Image Gallery in a web browser.
2. Click any image to view it in a larger size.
3. Use the previous and next buttons to navigate.
4. Press `Esc` to close the image view.
